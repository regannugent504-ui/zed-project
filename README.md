Reading Tracker Website — README and Decision Log

Project Overview

The Reading Tracker is a web application designed to help readers organize their books and track their reading progress. Users can add books, record the number of pages they have read, update book information, and see their progress toward finishing each book. The website is designed to be simple, accessible, and easy to use.

Technology Decisions

HTML: Used to structure the website and organize its content and forms.

CSS: Used to create the visual design, layout, progress bars, and responsive styling for different screen sizes.

JavaScript: Used to make the website interactive, including adding, editing, searching, filtering, and deleting books.

localStorage: Selected to save book information in the user's browser so the information remains available after refreshing the page.
