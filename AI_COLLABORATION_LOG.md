I used ChatGPT as a coding assistant to help develop my Reading Tracker website based on my Project Zed Plan. I provided the requirements for the website, including the ability to add books, track pages read, calculate reading progress, update saved entries, and save information using localStorage. ChatGPT generated the HTML, CSS, and JavaScript code for the website and helped implement features such as search, status filters, ratings, notes, and progress bars. I also used ChatGPT to understand the difference between JSON and HTML and to determine which format I needed for the website. I reviewed the generated code and used it as a starting point for building my project. The goal of this collaboration was to use AI to support coding and problem-solving while creating a functional, accessible, and user-friendly reading tracker.
